# Table of Contents

Builds a linked "jump to" list from the page's headings (H2/H3/H4). Clicking an item smooth-scrolls to that heading and marks it active (so the block shows the chapter you last jumped to). The list is generated from the surrounding content; the title above it is editable inline.

- **Server-side required:** No — purely client-side.
- **External dependencies:** None.

## Embed code

```html
<div data-cb-type="table-of-contents" data-cb-levels="h2h3" data-cb-accent-color="#3b82f6" role="navigation" aria-label="Table of contents">
    <p class="toc-title">On this page</p>
    <ul class="toc-list"></ul>
</div>
```

## Options (`data-cb-*` attributes)

| Attribute | Values | Default | Description |
|---|---|---|---|
| `data-cb-levels` | `h2` / `h2h3` / `h2h3h4` | `h2h3` | Which heading levels to include |
| `data-cb-accent-color` | any CSS color | `#3b82f6` | Active/hover link color |

## Notes

- The `.toc-list` is **generated by `mount`** from the headings around the block — leave it empty in the HTML. `mount` also assigns an `id` to any heading that lacks one (slugified from its text) so the links work.
- The `.toc-title` ("On this page") is normal, inline-editable text — restyle/rename it like any content.
- **Clicking a link smooth-scrolls to the heading and marks it active** — so an inline TOC shows the chapter you last jumped to. (`is-active` on the link.)
- **Live refresh in the editor:** the list rebuilds automatically when you add/remove a heading *or edit a heading's text* (a debounced observer, editor-only). On the live page it's built once on load, always current.

## Dark mode

Dark mode for the rendered block is the site's responsibility. Colors are CSS variables and `style.css` ships a ready-made dark palette **commented out** — uncomment it and point the selector at your site's theme trigger. The accent color stays as configured.

All styling is scoped under `[data-cb-type="table-of-contents"]`.
